# Community Board Ways to participate

Desktop (1440px) and mobile (390px) captures of the selected-board Ways to
participate section.

- `cb_source_backed-*`: Manhattan Community Board 2, with a retained upcoming
  meeting and closed full-board application evidence.
- `cb_unknown-*`: Bronx Community Board 2, which omits unsupported speaking and
  public-committee application paths while keeping records, sources, and
  board-local closed membership evidence.

Regenerate with:

```text
python3 tools/capture_community_board_ways_to_participate.py
```
