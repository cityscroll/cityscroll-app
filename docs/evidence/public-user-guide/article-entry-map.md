This is the article-entry map for connecting the published guide to the product.
Each product control group below may show **at most one** of these links.

| Product surface | Control group | Guide article | URL |
| --- | --- | --- | --- |
| Shared document mast and footer; home and search primary nav and footer | Site chrome | Guide home | `/guide/` |
| Following | Create / manage a watch | Follow a search | `/guide/how-to/follow-a-search/` |

| README examples | Maintainer and visitor entry | The matching Start here / How to page | `/guide/` and the three representative articles named in the README |

None of these URLs carry a watch token, session, or email. Returning from a
guide article uses the article's existing `return_to_task` link, which is a
public product route.
