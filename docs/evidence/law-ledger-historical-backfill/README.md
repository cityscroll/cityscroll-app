## Coverage interval statuses

Each section's timeline is split at every source-stated change date. A segment carries one
of four statuses, and a segment is never filled from a neighbouring segment:

| Status | Meaning | Basis |
| --- | --- | --- |
| `before_enactment` | The publisher records the section as added on the segment's end date | source stated |
| `unknown` | A change is recorded for the segment but no historical text is retained | source stated |
| `covered_by_retained_version` | A retained historical version covers the segment | source stated |
| `covered_by_current_snapshot` | The retained current text applies from the last recorded change | derived |

`covered_by_current_snapshot` is the only derived status. Its start comes from the last
change the publisher records, not from the observation timestamp, and it is labelled
`basis: derived` on every interval that carries it.

## Conflicting and insufficient evidence

The corpus scan found 54 citations published under more than one publisher record and 0
instruments stated with more than one effective date for the same provision. Every
conflicting observation is retained with `resolution: unresolved`; no source is promoted
over another and no record is dropped. None of the 54 falls inside this batch, so the
batch's own conflict list is empty and the corpus finding is published beside it under
`conflicts.corpus_summary` and `conflicts.outside_batch_examples`.

Insufficient evidence stays visible in three further places: a note fragment with no
readable instrument or operation is retained verbatim as an unparsed observation, an entry
with no stated effective date adds no interval boundary, and an acquisition that lacks
text, a validity start, a source reference, or the matching provision identity is rejected
with a named reason instead of becoming a version.

## Corpus boundary

The batch stays inside the NYC Administrative Code. RCNY rules, the City Charter, and the
construction codes are outside it. Where the publisher records a New York State chapter law
as amending an Administrative Code section, the change keeps the Administrative Code as its
target corpus while the instrument is recorded as `state_law` with a `ny-laws:` identity, so
it can never be read as a Local Law. The batch names 102 distinct instruments: 61 Local Laws
and 41 New York State chapter laws.
