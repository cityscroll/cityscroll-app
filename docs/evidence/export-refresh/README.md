# Export refresh evidence

`single-notice-before.xlsx` reproduces the former narrow notice workbook for public request `20260617050`. `single-notice-after.xlsx` is generated from the refreshed model and includes the action, event, lifecycle, entity, source, and rendered-context companion sheets.

The files use public record identifiers and a generic contact label. Regenerate them from the repository root with `node tools/build_export_refresh_evidence.mjs`.
