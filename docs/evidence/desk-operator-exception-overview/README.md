# Desk operator exception overview evidence

This directory records bounded isolated render evidence for the authenticated data-source exception overview. It contains no credentials, private diagnostic payloads, or captured image binaries.

The producer opens on monitoring and publication status plus a filterable exception table. Collecting-body topology remains a secondary view. Product uses join only declared first-class artifacts and their primary routes. Repair links reuse the existing queue identity.

Evidence boundaries:

- These captures are isolated producer renders, not live production observations.
- Inspection does not refresh a publisher, write a card, or perform a repair.
- Capture images remain ignored. The committed proof is this manifest: route, viewport, revision, data vintage, assertion, and render-content digest.
- The retained deployed source-state parity manifests in `docs/evidence/desk-source-state-parity/` stay bound to their recorded data revision.
