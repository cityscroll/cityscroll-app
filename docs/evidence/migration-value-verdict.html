Decision rule

Measured beats marketing. A claim is confirmed only when the after measurement directly tests the registered before claim. Estimated values stay labeled estimated; missing timestamps stay null; repeated check runs are not converted into incident counts. The migration can remain operationally sound while its entire value thesis remains only partly proved.
