# Deadlines through digest

Inspectable source → detail → email comparisons for sourced response deadlines.

These JSON examples are produced by `test/friction_t1_capability.test.mjs` and retain:

- one date-only native deadline (Contract Reporter 2138505)
- two exact-time City Record deadlines (DOB 20260707026, Governors Island 20260727019)

Each example records the source locator, transported digest fields, detail excerpt, preview atom deadline, and prepared-email subject/meta label under a fixed test clock.
