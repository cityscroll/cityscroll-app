Records-request path

The file exists. Agencies keep the contract file; PASSPort carries it for mayoral agencies; Comptroller BCA receives the registration package. The Comptroller’s FOIL unit has released hundreds of contracts on request (e.g. H+H HERRC). There is no bulk public dump of those PDFs.

  • Agency: OpenRecords / FOIL to the contracting agency
  • Comptroller: FOIL instructions

Do not

  • Parse contractData.js for attachments — there are none
  • Sell Checkbook purpose or notice prose as the contract file
  • Scrape authenticated PASSPort / Vault
  • Re-enable 2021 bid tabulations as modern awarded prices
  • Treat contract-response addresses as place of performance
