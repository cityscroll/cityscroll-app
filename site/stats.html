About these numbers

What the counts count
Each set counts one kind of record. The same record listed twice counts once. Sets are never added together.
Which days the use counts cover
Each column names its own days. The last day is counted up to the last check, so it is not a whole day. A period nobody measured is left unpublished, never shown as a zero.
How current this is
Each set states the date of the evidence it was counted from. No date comes from a publisher clock or from the build.
What this page cannot tell you
It cannot tell you how many people came, or whether a search answered the question. A count of searches is not a count of readers.
Site languages
The site has English and 10 more languages. Source text stays in English. A reader may ask for a translation.
What stays private
The search counts above are published. The searches themselves are not. Visits, watches, and email totals stay private. Read the source notes or open the public JSON.
