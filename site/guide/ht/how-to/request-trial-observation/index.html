Sous anglè: Request Trial Observation

Sous anglè: Prepare an OATH observation request and find the current CCRB trial grid without confusing either with a testimony or verdict process.

Dènye revizyon: 2026-11-25

Sous anglè: Choose the right request

Sous anglè: OATH and CCRB use different access paths. OATH asks an observer to contact its calendar unit about a selected trial. CCRB publishes a rolling trial grid. Neither path is a request to testify, and neither source turns an allegation into a finding.

Sous anglè: OATH — copy three exact fields

  1. Sous anglè: Open the official OATH trial calendar and choose a current row marked Scheduled For Trial.
  2. Sous anglè: Copy the row's index, date, and time. The index identifies a calendar listing; it is not, by itself, a complete session identifier.
  3. Sous anglè: Email OATHCalUnit@OATH.nyc.gov with those three fields and ask whether the trial is proceeding and for the observation location or remote access instructions.

Sous anglè: The request is a question to the calendar unit, not a confirmation that the trial will happen. Some proceedings are remote and some are in person; the calendar can be changed by settlements or adjournments. A conference entry is not an observation-trial entry, and a generated email draft must never send itself or record attendance.

Sous anglè: Example shape: Subject: Request to observe OATH trial — index [index] — [date], [time]. In the body, say that you would like to observe the trial listed under that index and ask the calendar unit to confirm whether it is proceeding and provide access instructions.

Sous anglè: CCRB — use the current rolling grid

Paj piblik pwosè CCRB a se lyen ofisyèl kalandriye pwosè aktyèl la, ke CCRB di li pibliye kat mwa davans. Louvri li pre jou ou planifye ale a paske dat yo ka chanje. Griy la ka montre yon awondisman kote enside a rive, yon ofisye, ak chaj, men awondisman enside a se pa kote odyans lan fèt epi chaj yo se akizasyon, pa konklizyon jije.

Sous anglè: The page does not provide a stable case identifier or a session start time in every row. Do not copy an inspected date list into a stale CityScroll calendar. Confirm the official page's current instructions before going to 1 Police Plaza.

Sous anglè: Return to the scheduled record

Sous anglè: After reading this guide, use the observation browse to return to the task. A scheduled detail page should link back to the relevant OATH or CCRB section above; that link carries your place in the explanation, not a promise that the publisher's schedule has stayed unchanged.
