Consulte el siguiente paso y los documentos de un proyecto de uso del suelo

Compruebe la etapa actual, la próxima oportunidad publicada y los documentos oficiales de un proyecto.

Última revisión: 2026-09-08

Paso 1 — Abra el proyecto

Abra proyectos de uso del suelo con JavaScript activado. Introduzca el nombre del proyecto en Código postal, dirección o vecindario sobre la lista; para practicar, use Timbale Terrace. Seleccione el título y compruebe el número 2022M0258. Leer aquí no envía nada ni inicia ninguna suscripción.

Paso 2 — Lea la etapa y la autoridad

En Dónde está esto, lea juntos Etapa actual, Actor actual y Cargo. La función indica si el organismo puede decidir o solo recomendar; una recomendación no es una aprobación. Después lea Siguiente etapa prevista y Próxima oportunidad publicada. El primero es el siguiente paso habitual; el segundo, una oportunidad publicada para participar cuando hay una fecha disponible.

Compruebe la etiqueta de cada fecha antes de planificar. Un intervalo calculado a partir de plazos legales de revisión no es una cita; los cómputos pueden suspenderse. Use la fuente oficial de una oportunidad publicada para confirmar dónde y cuándo participar.

Paso 3 — Abra los documentos presentados

En la página del proyecto, busque Documentos de decisión y abra un título de documento si aparece. Son decisiones publicadas de un organismo. Los documentos de solicitud, incluido un Racial Equity Report cuando se exige, tienen otro propósito; compruebe si el informe era obligatorio y si se observó antes de sacar conclusiones de su ausencia.

Use Abrir proyecto ZAP completo en la zona de documentos de decisión para abrir el registro completo en el Zoning Application Portal de la ciudad. Compruebe que coincida el número de proyecto y abra allí el documento presentado. Si CityScroll no enumera documentos, consulte el mismo registro del portal para comprobar el expediente publicado.

Cuando se desconoce una etapa o fecha

Un Dónde está esto desconocido significa que la evidencia disponible no establece la etapa. No published next opportunity found no significa que no vaya a haber ninguna. Una fuente not checked o marcada como desactualizada deja la respuesta sin determinar. Consulte el registro del proyecto en el portal y el calendario publicado del organismo correspondiente antes de hacer planes.

Un informe que has not been observed no está automáticamente retrasado ni ausente de la documentación del solicitante. Distíngalo de una conclusión explícita del editor de que no se presentó a tiempo.
