Ajoutez des dates à votre calendrier

Ajoutez un événement ou abonnez-vous à une liste datée, puis vérifiez le résultat dans votre calendrier.

Dernière vérification : 2026-09-08

Étape 1 — Choisissez les dates

Ouvrez Maintenant avec JavaScript activé. Aucun compte ni courriel n’est nécessaire. Agir avant liste les échéances d’action ; Bientôt liste les événements. Lisez la date de la ligne et ouvrez son titre pour vérifier le document publié avant de l’enregistrer.

Étape 2 — Enregistrez un événement

Ouvrez Réunions et sélectionnez le titre d’une réunion pour ouvrir sa page.

Sur la page d’une réunion, choisissez Add to calendar parmi ses actions. Cette commande n’apparaît que lorsque le document comporte une heure. Ouvrez le fichier téléchargé dans votre calendrier et vérifiez le titre, la date et l’heure de l’événement.

C’est une copie ponctuelle : elle ne sera pas mise à jour si l’événement change. Si seul un jour est publié, la commande est absente ; CityScroll n’invente pas d’heure. Pour une liste continue, passez à l’étape suivante.

Étape 3 — Ouvrez un abonnement au calendrier

Ouvrez Réunions. Saisissez un sujet dans Rechercher ; ouvrez Plus de filtres pour choisir Période ou Zone concernée. Choisissez ensuite S’abonner au calendrier dans la barre au-dessus des documents. La commande n’apparaît que si la liste comporte des éléments datés. Sinon, élargissez les filtres jusqu’à leur apparition. Le panneau nomme la liste à laquelle vous allez vous abonner.

Si le panneau des filtres masque la barre d’outils, fermez Plus de filtres et choisissez S’abonner au calendrier.

Étape 4 — Ajoutez l’abonnement dans votre calendrier

Dans ce panneau, choisissez la méthode prise en charge par votre application :

  • Ouvrir l’abonnement au calendrier ouvre le calendrier de votre appareil. Ajoutez-y l’abonnement ; dans Apple Calendar, définissez la fréquence Auto-refresh.
  • Copier l’URL d’abonnement copie une adresse. Dans Google Calendar, collez-la sous Other calendars → From URL ; dans Outlook, utilisez Add calendar → Subscribe from web.

Vérifiez que votre application liste un calendrier abonné et affiche les dates attendues. CityScroll ne peut pas confirmer qu’un abonnement a été ajouté ou actualisé. Importer un fichier téléchargé crée une copie ponctuelle ; seule une URL que le calendrier consulte régulièrement constitue un abonnement.

Les abonnements conservent les échéances sans heure comme entrées sur toute la journée et signalent les événements annulés. Les mises à jour suivent la fréquence d’actualisation de votre calendrier. Vérifiez le document officiel pour les changements de dernière minute.

Lorsque les dates manquent

Si Now liste une action sans date de clôture publiée, aucune échéance ne peut être exportée. Ouvrez Alertes pour suivre les mises à jour. Si une source could not be reached, la réponse est inconnue : rechargez avant de considérer la liste vide.
