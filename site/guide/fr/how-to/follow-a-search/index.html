Source anglaise : Step 1 — Set the topic and place

Source anglaise : Open Alertes with JavaScript switched on. Under Que souhaitez-vous suivre ?, choose a topic such as Contracts and RFPs. Under Where?, choose a borough or Any place. Open Affiner les résultats to add a keyword or agency. For contracts, open Affiner la correspondance to include any or all of a few words, treat an entry as an exact phrase, or exclude words. Example: include software, exclude maintenance, preview the awards, then tighten the exclusion if a useful record such as a Greenway project was removed because its body mentioned maintenance vehicles. Frozen award examples are published awards, not currently open bids. The selected choices describe an unsaved watch. No account or password is needed. This is separate from the city's own account system.

Source anglaise : Public meetings use the same Affiner la correspondance control. The board, place, and upcoming-event window you already chose stay the boundary. Extra wording only narrows it. Exact Council-matter watches and other topics do not offer these controls.

Source anglaise : Step 2 — Check the preview

Source anglaise : Press Aperçu des correspondances below the choices. Read the rule sentence in Résumé du suivi, then check Critères du suivi and the records under Aperçu. A preview is not a subscription: nothing is saved and no email is sent. Change a choice and press Actualiser les correspondances to revise it.

Source anglaise : The message No matches now — still watch for new means the loaded preview is empty. You can save a watch for future records, or widen a criterion and preview again. If the preview is not ready, use its retry control. The current matches are unknown.

Source anglaise : Step 3 — Create the watch

Source anglaise : Under Fréquence des courriels, choose Quotidien (on days with matches) or Hebdomadaire (Monday digest). Under Créer ce suivi, enter Adresse e-mail and press Créer un suivi. The watch exists as soon as the request succeeds. There is no confirmation email to click.

Source anglaise : Check for Vous êtes abonné : nous vous enverrons des courriels. Vous pouvez gérer ou annuler votre abonnement à tout moment. Keep the welcome email's manage link. If the page reports an error, use its retry instruction. An error does not confirm enrollment.

Source anglaise : Step 4 — Change or stop updates

Source anglaise : Open the manage link in a CityScroll email. On the watch's row, change the frequency and press Save, or choose Pause, Unpause, or Delete watch. Check the row's resulting state. Edits apply to the next digest, around 9am Eastern. Unsubscribe all watches stops all updates immediately, so use it only when that is what you want.

Quand les suivis enregistrés sont indisponibles

Source anglaise : Under Vos suivis, an unrecognized browser asks you to open a CityScroll email. Use that email's manage link. A link reported as invalid or expired needs replacing with the link in a recent email. If saved watches cannot load, use the offered retry. That failure does not mean they were deleted. A watch link reported as unrecognized has saved nothing: choose a topic on Following and start again.
