Source anglaise : Last reviewed 2026-09-08

Source anglaise : Step 1 — Open a connection's details

Source anglaise : Open Parks and Recreation with JavaScript switched on. No account is needed. Under Documents liés, choose Détails beside a record's title (announced as Détails by a screen reader). A Preuves du lien panel opens for that record.

Source anglaise : For the worked example, use Détails beside Update to Parks List of Qualifying Documents for Disability Membership Fee, if present. The example connection link opens that panel directly when the record is available.

Source anglaise : Step 2 — Read the basis and source

Source anglaise : In Preuves du lien, read the match label and date. In the example, Correspondance établie par un document publié and Matched to the agency's published name describe the basis. Under Comment ce lien a été établi, read the relation, issued rule. Open Avis du City Record in the panel to compare the official source, then return.

Source anglaise : This supports the stated connection, not a finding of compliance or wrongdoing. How records are connected explains the other match labels.

Source anglaise : Step 3 — Reopen the evidence from its link

Source anglaise : At the bottom of the panel, choose Copier le lien vers cette relation. Copy the full browser address and paste it into a new tab. Check that the same record's Preuves du lien is expanded. Keep this address with the claim it supports.

Source anglaise : When there is no source or panel

Source anglaise : Some contract connections have no separate notice source. Open the linked record title in the panel and use that record's own source link. Missing source evidence is not proof of no relationship. If a copied address opens no panel, return to Documents liés and use Détails to select a connection currently on the page. Without JavaScript, read the records directly. The panel is unavailable.
