Source anglaise : Step 1 — Choose an observation experience

Source anglaise : These are six different experiences, not six versions of the same meeting. Read the preparation note before opening a calendar or registration page. A dated CityScroll detail page is a way back to the matching guide section; it does not change the access rules of the official publisher.

Source anglaise : Watch a PDC public review

Source anglaise : What you see: A Planning Commission public review meeting, including presentations and the commission's public proceedings. Watching is separate from speaking.

Source anglaise : Access: Follow the scheduled PDC meeting's official page or meeting link. You can watch without signing up to testify. The Teams testimony signup, when offered, is a separate action and is not required merely to observe.

Source anglaise : Prepare: Open the agenda and confirm the date, time, meeting format, and any published materials. Keep the official page open in case the agency changes the details.

Source anglaise : Official next step: Read the Planning Commission meeting information. For a scheduled item, return to its PDC detail page.

Source anglaise : Listen to a BSA executive review

Source anglaise : What you see: A Board of Standards and Appeals executive review of applications and cases. This is listen-only for an observer; the executive review is not a public testimony signup.

Source anglaise : Access: Use the official BSA calendar or the meeting link on the scheduled detail. No bidder or speaker registration is implied by watching.

Source anglaise : Prepare: Read the agenda, case numbers, and any attached hearing material. Do not treat a prior case date in a case history as another upcoming session.

Source anglaise : Official next step: Open the BSA calendar. For a scheduled item, return to its BSA detail page.

Source anglaise : Request an OATH trial observation

Source anglaise : What you see: An administrative trial listed in OATH's current calendar. Some trials are remote and some are in person, and the calendar does not confirm that a trial will proceed.

Source anglaise : Access: Ask OATH's calendar unit for observation access. Email OATHCalUnit@OATH.nyc.gov with the calendar index, date, and time. Copying the generated request is not sending it and does not promise admission.

Source anglaise : Prepare: Select a current row marked for trial, then copy its index, date, and start time exactly. Ask the calendar unit to confirm whether it is proceeding and to provide the location or remote instructions. A conference row is not a trial row.

Source anglaise : Official next step: Open OATH's trial calendar. Use the trial-observation request guide for the email checklist.

Source anglaise : Visit a CCRB public trial

Source anglaise : What you see: A public Civilian Complaint Review Board disciplinary trial at 1 Police Plaza. The officer, borough, and charges in the rolling grid are case information; charges are allegations, not findings.

Source anglaise : Access: Use the current official rolling three-week trial grid. It is the source of the available dates, and dates can change.

Source anglaise : Prepare: Check the grid immediately before you go. It does not provide a stable case identifier or a session start time in every row, so do not copy an old date list into a CityScroll event or infer a venue from the incident borough.

Source anglaise : Official next step: Open the current CCRB trial grid. A scheduled detail can return to the CCRB guide section.

Source anglaise : Enter a Hart Island public-visit program

Source anglaise : What you see: A Ranger-led public visit to Hart Island. General public visits are different from close-person gravesite visits; you do not need a personal connection for the general program.

Source anglaise : Access: Apply through the official Parks registration program for a selected visit date. If demand exceeds capacity, the program uses a lottery. A selected-Tuesday policy is not a weekly event schedule.

Source anglaise : Prepare: Read the visitation rules and wait for the registration program to publish dates. Do not assume availability, a recurring Tuesday event, or a confirmed place from this guide.

Source anglaise : Siguiente paso oficial: Read Hart Island visitation information. The page's registration instructions are the authority for selected dates and capacity.

Source anglaise : Watch a DDC bid opening

Source anglaise : What you see: A Department of Design and Construction construction bid opening, where submitted prices may become public. A price read at an opening is not a contract award.

Source anglaise : Access: Use the official DDC construction contracts page and its live bid-opening or results links. Watching an opening is separate from becoming a bidder and does not require bidder registration.

Source anglaise : Prepare: Read the agency's instructions and distinguish a live opening from preliminary bid results. This guide does not invent a recurring event, confirmed availability, solicitation identity, or registration requirement.

Source anglaise : Official next step: Open DDC construction contracts or read preliminary bid results.

Source anglaise : Keep the official page in view

Source anglaise : The official agency page controls the current access details. CityScroll can explain the experience and connect a scheduled record back to this guide, but an undated program is not an upcoming event and a calendar row is not proof that a proceeding will happen.
