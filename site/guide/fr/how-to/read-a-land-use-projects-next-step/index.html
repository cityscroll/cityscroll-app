Consultez la prochaine étape et les documents d’un projet d’utilisation des sols

Vérifiez l’étape actuelle d’un projet, sa prochaine occasion publiée et ses documents officiels.

Dernière vérification : 2026-09-08

Étape 1 — Ouvrez le projet

Ouvrez les projets d’utilisation des sols avec JavaScript activé. Saisissez le nom du projet dans Code postal, adresse ou quartier au-dessus de la liste ; utilisez Timbale Terrace pour vous exercer. Sélectionnez son titre et vérifiez le numéro 2022M0258. Lire ici n’envoie rien et ne démarre aucun abonnement.

Étape 2 — Lisez l’étape et l’autorité

Dans Où en est ce projet, lisez ensemble Étape actuelle, Acteur actuel et Poste. Le rôle indique si l’organisme peut décider ou seulement recommander ; une recommandation n’est pas une approbation. Lisez ensuite Prochaine étape prévue et Prochaine occasion publiée. Le premier est l’étape suivante habituelle, le second une occasion publiée de participer lorsqu’une date est disponible.

Vérifiez le libellé de chaque date avant de planifier. Une période calculée à partir de délais légaux d’examen n’est pas un rendez-vous ; les décomptes peuvent être suspendus. Utilisez la source officielle d’une occasion publiée pour confirmer où et quand participer.

Étape 3 — Ouvrez les documents déposés

Sur la page du projet, trouvez Documents de décision et ouvrez un titre de document s’il y en a un. Ce sont les décisions publiées d’un organisme. Les pièces de demande, dont un Racial Equity Report lorsqu’il est exigé, ont un autre rôle ; vérifiez si ce rapport était requis et observé avant de conclure de son absence.

Utilisez Ouvrir le projet ZAP complet dans la zone des documents de décision pour ouvrir le dossier complet dans le Zoning Application Portal municipal. Vérifiez le numéro de projet et ouvrez-y le document déposé. Si CityScroll ne liste aucun document, utilisez le même dossier du portail pour vérifier les pièces publiées.

Lorsqu’une étape ou une date est inconnue

Un Où en est ce projet inconnu signifie que les preuves disponibles n’établissent pas l’étape. No published next opportunity found ne signifie pas qu’il n’y en aura aucune. Une source not checked ou signalée comme ancienne laisse la réponse inconnue. Consultez le dossier du portail et le calendrier publié de l’organisme concerné avant de planifier.

Un rapport qui has not been observed n’est pas automatiquement en retard ou absent du dossier du demandeur. Distinguez cela d’un constat explicite de l’éditeur selon lequel il n’a pas été déposé à temps.
