Source anglaise : As of a day

Source anglaise : Agency pages carry an À la date du filter. Give it a date and the page keeps only the linked records whose publisher or event date falls on or before that day. The set contains records linked now. Undated records are excluded. Sharing the address reopens the same day.

Source anglaise : What it does not do is reconstruct everything CityScroll knew on that date. It filters records by their own dates. What had been collected by a given day is a different question, and this control does not answer it.

Source anglaise : Four kinds of blank

Source anglaise : An empty field is not one thing, and the difference between these is the difference between an absence of publication and an absence of an event.

  • Source anglaise : Pas encore affiché ici — the city publishes this, and CityScroll has not joined it. The gap is here, not in the city's publishing.
  • Source anglaise : The city does not publish this — no public, joinable release of the field is known. Where there is an obvious place it would appear if it were released, the record names it.
  • Source anglaise : Not yet joined — the record exists and the connecting record does not, so the two cannot be put together with confidence.
  • Source anglaise : Inconnu — the source itself carries no value.

Source anglaise : None of these is a zero. "No awards found for this agency" means none were found in the sources CityScroll reads, and several agencies publish their awards somewhere those sources do not reach. The classification behind these states is written down and kept as a document of its own.

Source anglaise : A closed window is still a real record

Source anglaise : Application windows, comment periods and hearing dates pass. When they do, the record stays, and it is still worth reading: it shows you what the process looks like, what the conditions were, and where the official notice lives.

Source anglaise : What it is not is a current invitation. A civil-service exam whose filing window has closed shows that window marked closed, and following its apply link will not get you a place. The lesson is transferable to a window that is open. The opportunity is not.

Source anglaise : An estimate is not a deadline

Source anglaise : Some pages show how long something has usually taken in the past — the gap between comments closing and a rule being adopted, for instance. That is drawn from past published records, it is labelled as an estimate, and it never appears as a confirmed date. Where a real official date exists, it replaces the estimate rather than sitting beside it.

Source anglaise : No published outcome is not a decision

Source anglaise : Many proceedings publish their result long after the event, in a different record, sometimes in a form that cannot be joined to the one you are reading. A hearing with no published outcome is not a hearing where nothing was decided. When you need the result, the official source on the record is where to go and ask.
