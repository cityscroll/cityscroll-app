이 번역은 기계로 초벌 번역되었으며 아직 원어민의 검토를 거치지 않았습니다.

사용 방법… · 사용 안내

기록 모으고 메모하고 내보내기

기록을 고정하고 메모를 저장하며 로컬 내보내기와 공유 사본 중 선택하세요.

마지막 검토 2026-09-08

1단계 — 기록 두 개 고정하기

JavaScript를 켜고 West 50th Street 낙찰 공고를 여세요. 기록의 작업 중 고정를 선택하세요. 확인 표시는 작업 공간 링크와 항목 수를 보여 줍니다. 해당 단체를 열어 거기서도 고정를 선택하세요. Pin은 검색 결과가 아닌 개별 기록에 표시됩니다.

2단계 — 메모 추가하고 확인하기

페이지 바닥글의 내 조사 또는 My investigation를 여세요. 두 기록이 모두 조사 워크스페이스 · 이 브라우저에만 저장됨 아래에 있는지 확인하세요. 계정은 필요 없습니다. 기록 아래 메모 추가…에 입력하고 입력란 밖을 눌러 저장하세요. 새로고침한 뒤 메모가 남아 있는지 확인하세요.

일반적인 로그아웃 방문에서는 모음이 이 브라우저에 남으며, 사이트 데이터를 지우면 사라집니다. CityScroll 이메일로 인식된 세션은 여러 기기에서 고정을 유지할 수 있습니다.

3단계 — 사본 내보내기

항목 아래에서 스프레드시트는 .csv로 내보내기, 구조화된 데이터는 .json으로 내보내기를 선택하세요. 내려받은 파일을 열어 기록, 메모, 링크를 확인하세요. 두 파일 모두 고정된 사본이며 업데이트되지 않습니다. 조사 자료 인쇄는 브라우저 인쇄 창을 열어 인쇄하거나 PDF로 저장합니다.

4단계 — 메모를 확인한 뒤에만 공유하기

항목 아래 공유(읽기 전용 링크)를 선택하기 전에 메모를 읽으세요. 이 작업은 메모를 포함한 스냅샷을 CityScroll에 올립니다. 링크가 있는 누구나 90일 동안 비밀번호 없이 읽을 수 있습니다. 로컬 목록과 별개이며 이후 수정은 반영되지 않습니다.

반환된 링크를 새 탭에서 여세요. Shared investigation에는 편집 기능 없이 기록과 메모가 표시되어야 합니다. 받은 사람은 자신의 조사로 사본을 가져올 수 있습니다.

작업을 사용할 수 없을 때

공유 중 서버 오류가 표시되면 로컬 목록을 유지하고 .csv로 내보내기 또는 .json으로 내보내기를 사용하세요. 연구 패키지 고정에는 지원되는 비교가 필요하므로 일반 고정 기록에는 위 내보내기를 사용하세요.

전체 삭제를 선택하면 확인 절차 없이 로컬 조사가 즉시 비워집니다. 목록을 없앨 준비가 되었을 때만 사용하세요. 기존 내보내기 파일과 공유 스냅샷은 남습니다. 빈 작업 공간은 개별 기록에서 고정를 선택해 다시 시작하는 방법을 안내합니다.
