Добавьте даты в календарь

Добавьте событие или подпишитесь на датированный список, затем проверьте результат в календаре.

Последняя проверка 2026-09-08

Шаг 1 — Выберите даты

Откройте Сейчас с включённым JavaScript. Учётная запись и почта не нужны. Действовать до перечисляет сроки действий, Скоро — события. Прочитайте дату строки и откройте заголовок для проверки опубликованной записи перед сохранением.

Шаг 2 — Сохраните одно событие

Откройте Заседания и выберите название заседания, чтобы открыть его страницу.

На странице заседания выберите Add to calendar среди действий. Элемент есть только при наличии времени суток. Откройте загруженный файл в календаре и проверьте заголовок, дату и время.

Это однократная копия: при изменении события она не обновится. Если опубликован лишь день, элемента нет: CityScroll не выдумывает время. Для продолжающегося списка используйте следующий шаг.

Шаг 3 — Откройте подписку на календарь

Откройте Заседания. Введите тему в Поиск; откройте Другие фильтры, чтобы выбрать Период или Затрагиваемая территория. Затем выберите Подписаться на календарь в панели над записями. Элемент появляется только при наличии датированных элементов. Если его нет, расширьте фильтры до появления датированных записей. Панель называет список будущей подписки.

Если панель фильтров закрывает панель инструментов, закройте Другие фильтры и выберите Подписаться на календарь.

Шаг 4 — Добавьте подписку в приложение календаря

В панели выберите способ, поддерживаемый вашим приложением:

  • Открыть подписку на календарь открывает календарь устройства. Добавьте подписку там; в Apple Calendar задайте частоту Auto-refresh.
  • Копировать URL подписки копирует адрес. В Google Calendar вставьте его в Other calendars → From URL; в Outlook используйте Add calendar → Subscribe from web.

Проверьте, что приложение показывает подписной календарь и ожидаемые даты. CityScroll не может подтвердить добавление или обновление подписки. Импорт загруженного файла — разовая копия; подписка — только URL, который календарь продолжает получать.

Подписки сохраняют сроки без времени как события на весь день и помечают отменённые события отменёнными. Обновления следуют расписанию приложения календаря. Проверяйте официальный документ для последних изменений.

Когда дат нет

Если Now перечисляет действие без опубликованной даты закрытия, экспортировать срок нельзя. Вместо этого откройте Оповещения для отслеживания обновлений. Если источник could not be reached, ответ неизвестен: перезагрузите, прежде чем считать список пустым.
