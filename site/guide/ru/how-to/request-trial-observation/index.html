Английский источник: Request Trial Observation

Английский источник: Prepare an OATH observation request and find the current CCRB trial grid without confusing either with a testimony or verdict process.

Английский источник: Last reviewed 2026-09-15

Английский источник: Choose the right request

Английский источник: OATH and CCRB use different access paths. OATH asks an observer to contact its calendar unit about a selected trial. CCRB publishes a rolling trial grid. Neither path is a request to testify, and neither source turns an allegation into a finding.

Английский источник: OATH: copy three exact fields

  1. Английский источник: Open the official OATH trial calendar and choose a current row marked Scheduled For Trial.
  2. Английский источник: Copy the row's index, date, and time. The index identifies a calendar listing; it is not, by itself, a complete session identifier.
  3. Английский источник: Email OATHCalUnit@OATH.nyc.gov with those three fields and ask whether the trial is proceeding and for the observation location or remote access instructions.

Английский источник: The request is a question to the calendar unit, not a confirmation that the trial will happen. Some proceedings are remote and some are in person; the calendar can be changed by settlements or adjournments. A conference entry is not an observation-trial entry, and a generated email draft must never send itself or record attendance.

Английский источник: Example shape: Subject: Request to observe OATH trial — index [index] — [date], [time]. In the body, say that you would like to observe the trial listed under that index and ask the calendar unit to confirm whether it is proceeding and provide access instructions.

Английский источник: CCRB: use the current rolling grid

Английский источник: The CCRB public trial page is the official link for the current rolling three-week grid. Open it close to the day you plan to attend because dates are subject to change. The grid may show an incident borough, officer, and charges, but the incident borough is not the venue and charges are allegations, not adjudicated findings.

Английский источник: The page does not provide a stable case identifier or a session start time in every row. Do not copy an inspected date list into a stale CityScroll calendar. Confirm the official page's current instructions before going to 1 Police Plaza.

Английский источник: Return to the scheduled record

Английский источник: After reading this guide, use the observation browse to return to the task. A scheduled detail page should link back to the relevant OATH or CCRB section above; that link carries your place in the explanation, not a promise that the publisher's schedule has stayed unchanged.
