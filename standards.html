The accessibility target, and where it's headed

Today
New York City's own website accessibility statement (opens in new tab) targets WCAG 2.1 Level AA and describes the City's sites as "partially conformant."
January 2027
New York State's technology law (STL §103-d (opens in new tab)) requires State Entity websites to move up to WCAG 2.2 Level AA. That binds state agencies, not New York City directly — but it is the clearest published signal of where the standard is heading next.

CROL-List's own accessibility posture

These are targets and continuous observations, not a certification.

CROL-List target
CROL-List targets WCAG 2.2 Level AA today.
Continuous observations
  • The axe accessibility gate runs on every pull request across each public page and activated tab state. A new critical or serious violation fails the build.
  • The Local Law 30 table above reads the site's current language switcher live. It changes when a language is added to or removed from the switcher.
  • The reading-level ratchet runs on every pull request across the public pages. A page that gets harder to read than its committed baseline fails the gate.
